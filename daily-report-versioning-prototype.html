What counts as a new version?

This demo applies the same submitted corrections to two Daily Report models. Compare whether each correction saves a full report snapshot or versions only the field or activity entry that changed.

Prototype assumption: the report begins as a prepared draft. Draft changes before the first submission are not modeled because their version rule is still open. This demo uses in-memory state only; roles are shown as context, not enforced as permissions.
